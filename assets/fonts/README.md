# فونت‌های نسخه بازطراحی‌شده

فونت اصلی تمام خروجی‌های تازه، **Vazirmatn 33.003** از [مخزن رسمی وزیرمتن](https://github.com/rastikerdar/vazirmatn/tree/v33.003/fonts/ttf) است. وزن‌های Regular، Medium، Bold و ExtraBold همراه مجوز `Vazirmatn-OFL.txt` نگهداری می‌شوند. فایل‌های TTF بدون تغییر دریافت شده‌اند.

برای ساخت شکل‌ها یا مشاهده Word با همین قلم، این چهار فایل را در سیستم نصب کنید. PDF فونت‌ها را در خود دارد و به نصب روی دستگاه خواننده نیاز ندارد.

`DejaVuSans.ttf` با مجوز همراه فقط برای نمادهای فاقد گلیف در وزیرمتن، مانند حروف یونانی و پیکان، استفاده می‌شود. توان‌ها و زیرنویس‌ها با خود وزیرمتن و تنظیم عمودی ساخته می‌شوند؛ رقم‌ها از فونت نماد استفاده نمی‌کنند.

فونت‌های Noto و B Nazanin از مرحله قبلی برای سابقه حفظ شده‌اند و ابزار ساخت جدید از آنها استفاده نمی‌کند. اسناد تاریخی و ورودی‌های آرشیوشده نیز نسخه اصلی خود را حفظ می‌کنند.
